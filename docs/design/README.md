These are the canvas's own source files, not app code. They only render on the canvas (they need its runtime, `support.js`, which is not here), so open the canvas link to see them and click through them in Play mode. Read them here for exact values: colors, sizes, spacing, layout, and the sample data in each file's `renderVals()`. The data is made up.

If the canvas changes, these copies do not follow; copy the board again.
